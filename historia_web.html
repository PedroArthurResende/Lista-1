Evolução da Internet e da Web

A Internet surgiu a partir da necessidade de conectar computadores em rede. Com o tempo, tecnologias como ARPANET, TCP/IP e DNS ajudaram a formar a base da comunicação moderna.

Já a World Wide Web foi criada por Tim Berners-Lee no CERN, permitindo o acesso a documentos ligados por hiperlinks.

Uma referência muito importante é Tim Berners-Lee, considerado o criador da Web. Seu trabalho no CERN ajudou a transformar a forma como acessamos informações.

Linha do tempo textual

  1. Surgimento das redes de computadores para troca de informações.
  2. Criação da ARPANET, uma das primeiras redes importantes.
  3. Uso do protocolo TCP/IP para comunicação entre redes.
  4. Criação do DNS para facilitar o acesso por nomes de domínio.
  5. Criação da World Wide Web por Tim Berners-Lee.
  6. Desenvolvimento do HTML para estruturar páginas.
  7. Uso do HTTP para comunicação entre navegador e servidor.
  8. Popularização dos navegadores e servidores web.
  9. Evolução da Web 1.0 para aplicações Web modernas.

Alguns conceitos

Internet
Rede mundial que conecta computadores e outros dispositivos.
Web
Serviço da Internet usado para acessar páginas e sites.
HTML
Linguagem de marcação usada para estruturar páginas.
HTTP
Protocolo usado na comunicação entre navegador e servidor.

Web 1.0 e Web moderna

A Web 1.0 era mais simples, com páginas estáticas e pouca interação. Já as aplicações Web modernas permitem login, compras, redes sociais, vídeos, sistemas online e muito mais.

Exemplo simples: H2O usa subíndice, enquanto 102 usa sobrescrito.

Marcos históricos

Principais marcos da Internet e da Web
Ano Acontecimento Importância
1960 Surgimento das redes de computadores Início das ideias de comunicação entre máquinas.
1969 ARPANET Base para o desenvolvimento da Internet.
1983 TCP/IP Padronizou a comunicação entre redes.
1984 DNS Facilitou o acesso por nomes de domínio.
1989 Criação da Web Permitiu o uso de páginas ligadas por hiperlinks.
1991 Primeiro site publicado Marco inicial da Web pública.
A Web continua evoluindo até hoje.

Observação final
