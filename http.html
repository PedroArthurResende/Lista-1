HTTP na prática: requisição e resposta

Início | História da Web | Estados | Currículo | Contato

O que é HTTP?

HTTP significa HyperText Transfer Protocol. Ele é o protocolo usado para permitir a comunicação entre o navegador do usuário e o servidor onde o site está hospedado.

Cliente, servidor, requisição e resposta

O cliente geralmente é o navegador, como Chrome, Firefox ou Edge. O servidor é o computador que guarda e envia os arquivos do site.

Quando acessamos uma página, o navegador envia uma requisição HTTP. Depois disso, o servidor devolve uma resposta HTTP com o conteúdo solicitado.

Métodos GET e POST

O método GET é usado para solicitar dados, como abrir uma página.

O método POST é usado para enviar dados, como informações de um formulário.

Exemplo de requisição HTTP

GET /index.html HTTP/1.1
Host: www.exemplo.com
User-Agent: Navegador

Exemplo de resposta HTTP

HTTP/1.1 200 OK
Content-Type: text/html

<html>
    <body>
        <h1>Página encontrada</h1>
    </body>
</html>

Códigos de status HTTP

Código Significado
200 OK. A requisição foi bem-sucedida.
301 Movido permanentemente para outro endereço.
400 Requisição inválida.
403 Acesso proibido.
404 Página não encontrada.
500 Erro interno no servidor.
