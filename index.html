Portal de Estudos sobre Web e HTML

Este site foi criado como atividade prática da disciplina de Programação para Internet. O objetivo é reunir páginas simples em HTML sobre Internet, Web, HTTP, currículo e contato.

Internet e Web

A Internet é a grande rede mundial que conecta computadores e dispositivos. A Web é um serviço que funciona dentro da Internet, permitindo acessar páginas por navegadores. Ou seja, a Web usa a Internet para exibir sites, links, imagens e outros conteúdos.

Sequência sugerida de leitura
